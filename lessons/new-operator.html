Konstruktor, new operatori

Oddiy {...} sintaksisi bitta obyekt yaratishga qulay. Ammo bir-biriga o'xshash ko'plab obyektlarni — masalan, ko'p foydalanuvchi, mahsulot yoki menyu bandini — yaratish kerak bo'lganda, konstruktor funksiyalar va new operatori yordamga keladi.

Konstruktor funksiya

Konstruktor funksiya — texnik jihatdan oddiy funksiya. Ammo uni boshqalardan ajratib turuvchi ikkita kelishuv (konvensiya) bor:

  1. Nomi bosh harf bilan boshlanadi (masalan, User, Car);
  2. U faqat new operatori bilan chaqirilishi kerak.
konstruktor.js
// natija shu yerda chiqadi

Bu yerda User funksiyasini new User("Jasur") ko'rinishida chaqirdik. Natijada tayyor, xossalari to'ldirilgan yangi obyekt qaytdi.

new nima qiladi? (4 qadam)

Funksiya new bilan chaqirilganda quyidagi qadamlar sodir bo'ladi:

  1. Yangi bo'sh obyekt yaratiladi va u this'ga tayinlanadi;
  2. Funksiya tanasi bajariladi. Odatda u this'ni o'zgartiradi, unga yangi xossalar qo'shadi;
  3. this qiymati qaytariladi (return);
  4. Ya'ni this avtomatik return qilinadi — buni o'zimiz yozishimiz shart emas.

Boshqacha aytganda, new User(...) quyidagiga o'xshash ishlaydi:

function User(name) {
  // this = {};  (yashirin tarzda)

  // this'ga xossalar qo'shiladi
  this.name = name;
  this.isAdmin = false;

  // return this;  (yashirin tarzda)
}
Demak new User("Jasur") natijasi shunday obyekt bilan bir xil:
let user = { name: "Jasur", isAdmin: false };
Farqi — konstruktor bilan biz istalgancha new User(...) chaqirib, ko'p obyekt yarata olamiz.

this — hozirgi obyekt

Konstruktor ichida this — hozir yaratilayotgan yangi obyektga ishora qiladi. Unga xossa va metod qo'shamiz:

this-metod.js
// natija shu yerda chiqadi

Har bir new chaqiruvi mustaqil obyekt yaratadi: a va b bir-biridan mutlaqo ajralgan.

return konstruktor ichida

Odatda konstruktorlarda return yozilmaydi — ular this'ni avtomatik qaytaradi. Ammo agar return mavjud bo'lsa, quyidagi qoida amal qiladi:

  • return <obyekt> — o'sha obyekt qaytariladi (this o'rniga);
  • return <primitiv> yoki bo'sh return — e'tiborsiz qoldiriladi, baribir this qaytadi.
return.js
// natija shu yerda chiqadi
Argumentlarsiz konstruktorni qavssiz ham chaqirish mumkin: new User = new User(). Ammo qavsni yozish yaxshi uslub hisoblanadi — kod aniqroq bo'ladi.

new.target

Ilg'or va kamdan-kam ishlatiladigan sintaksis new.target funksiya ichida uning new bilan chaqirilgan-chaqirilmaganini tekshirishga imkon beradi:

  • Oddiy chaqiruvda new.target — undefined;
  • new bilan chaqirilsa — funksiyaning o'ziga teng bo'ladi.
new-target.js
// natija shu yerda chiqadi
Amaliyotda new.target deyarli kerak emas. Uni ba'zan funksiyani newsiz ham new bilan ham bir xil ishlashiga majburlash uchun ishlatishadi, lekin bu kod o'qilishini murakkablashtiradi.

Xulosa

  • Konstruktor funksiya — bosh harf bilan nomlanuvchi va new bilan chaqiriladigan oddiy funksiya;
  • new yangi bo'sh obyekt yaratadi (this), funksiya tanasini bajaradi va this'ni avtomatik qaytaradi;
  • Konstruktor ichida this — yaratilayotgan yangi obyekt;
  • return <obyekt> yozilsa o'sha obyekt qaytadi; primitiv return e'tiborsiz qoladi;
  • new.target chaqiruv turini tekshiradi, lekin kamdan-kam kerak.
