Kirish

JavaScript — bu veb-sahifalarni "jonli" qiladigan dasturlash tili. Ushbu darsda uning nima ekanligi va qanday ishlashi bilan tanishamiz.

JavaScript nima?

JavaScript (qisqacha JS) — bu veb-brauzerda ishlaydigan dasturlash tili. U 1995-yilda yaratilgan bo'lib, bugungi kunda dunyodagi eng ommabop dasturlash tillaridan biridir.

Dastlab JavaScript faqat brauzerda ishlagan bo'lsa, endi u Node.js yordamida serverlarda, mobil ilovalarda va hatto ish stoli dasturlarida ham ishlaydi.

JavaScript va Java — bu ikki butunlay boshqa til. Nomlari o'xshash bo'lsa-da, ular bir-biriga bog'liq emas.

JavaScript nimalar qila oladi?

  • Sahifaga yangi HTML elementlar qo'shish yoki mavjudlarini o'zgartirish;
  • Foydalanuvchi harakatlariga (tugma bosish, sichqoncha harakati) javob berish;
  • Server bilan ma'lumot almashish (sahifani yangilamasdan);
  • Ma'lumotlarni brauzerda saqlash;
  • Animatsiyalar va interaktiv elementlar yaratish.

Birinchi dastur

An'anaga ko'ra, birinchi dastur ekranga "Salom, dunyo!" matnini chiqaradi. JavaScript'da buni console.log() buyrug'i orqali qilamiz:

misol.js
Ctrl+Enter bilan ishga tushiring
// natija shu yerda chiqadi
Yuqoridagi kodni o'zgartirib, "Ishga tushirish" tugmasini bosib ko'ring! Masalan, o'z ismingizni chiqaring.

Kod qanday yoziladi?

JavaScript kodida har bir buyruq odatda nuqta-vergul (;) bilan tugaydi. Izohlar (comments) esa kodni tushuntirish uchun ishlatiladi va dasturga ta'sir qilmaydi:

// Bu bir qatorli izoh

/* Bu esa
   ko'p qatorli izoh */

console.log("Izohlar dasturga ta'sir qilmaydi");
Izohlar boshqa dasturchilar (va kelajakdagi siz uchun) kodni tushunishni osonlashtiradi. Ulardan bemalol foydalaning!

Xulosa

  • JavaScript — brauzer va serverda ishlaydigan mashhur dasturlash tili;
  • console.log() yordamida natijani ekranga chiqaramiz;
  • Izohlar (// va /* */) kodni tushuntirish uchun xizmat qiladi.
