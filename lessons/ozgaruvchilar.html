O'zgaruvchilar

O'zgaruvchi (variable) — bu ma'lumotni saqlash uchun "nomlangan qutil​cha". Dasturlarda ma'lumotlar aynan o'zgaruvchilarda saqlanadi.

O'zgaruvchi yaratish

JavaScript'da o'zgaruvchi yaratish uchun let kalit so'zidan foydalanamiz:

let ism = "Ali";
let yosh = 25;

Bu yerda ism o'zgaruvchisiga "Ali" qiymati, yosh o'zgaruvchisiga esa 25 qiymati berildi. Endi bu qiymatlarni istalgan joyda ishlatishimiz mumkin:

ozgaruvchilar.js
// natija shu yerda chiqadi

let, const va var

JavaScript'da o'zgaruvchi e'lon qilishning uch usuli bor:

let — o'zgaruvchan qiymat

Qiymati keyinchalik o'zgarishi mumkin bo'lgan o'zgaruvchilar uchun let ishlatiladi.

const — o'zgarmas qiymat (konstanta)

Qiymati o'zgarmaydigan o'zgaruvchilar uchun const ishlatiladi. Uni qayta belgilashga urinsangiz, xatolik yuz beradi:

const pi = 3.14;
pi = 3.15; // ❌ Xatolik: const qiymatini o'zgartirib bo'lmaydi
Amaliyotda: qiymat o'zgarmasligini bilsangiz, const ishlating. Faqat o'zgarishi kerak bo'lganda let ga o'ting. Bu kodni xavfsizroq qiladi.

var — eski usul

var — JavaScript'ning eski o'zgaruvchi e'lon qilish usuli. Zamonaviy kodda uni ishlatmaslik tavsiya etiladi. Uni let va const almashtirgan.

O'zgaruvchiga nom berish qoidalari

  • Nom faqat harflar, raqamlar, $ va _ belgilaridan iborat bo'lishi mumkin;
  • Nom raqam bilan boshlana olmaydi (2ism ❌, ism2 ✅);
  • JavaScript katta-kichik harflarni farqlaydi: yosh va Yosh — bu ikki xil o'zgaruvchi;
  • Nom mazmunli bo'lishi kerak: x emas, foydalanuvchiYoshi yaxshiroq.
JavaScript'da odatda o'zgaruvchi nomlari camelCase uslubida yoziladi: birinchi so'z kichik harf bilan, keyingilari katta harf bilan boshlanadi. Masalan: foydalanuvchiIsmi.

Amaliy misol

Ikki o'zgaruvchini qo'shib, natijani chiqaramiz:

hisob.js
// natija shu yerda chiqadi

Xulosa

  • O'zgaruvchi — ma'lumot saqlaydigan nomlangan joy;
  • let — o'zgaruvchan qiymat uchun;
  • const — o'zgarmas qiymat (konstanta) uchun;
  • var — eskirgan, ishlatmang;
  • O'zgaruvchi nomlari mazmunli va camelCase uslubida bo'lsin.
