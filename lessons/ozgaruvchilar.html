O'zgaruvchilar

Ko'pincha dasturga ma'lumot bilan ishlash kerak bo'ladi. Masalan, onlayn do'kon tovarlarni va xaridlar savatini saqlaydi. Bu ma'lumotni saqlash uchun o'zgaruvchilar ishlatiladi.

O'zgaruvchi nima?

O'zgaruvchi (variable) — bu ma'lumot uchun "nomlangan qutixona". Uning ichiga har qanday qiymat — matn, son yoki boshqa narsa joylashtirish mumkin.

JavaScript'da o'zgaruvchi yaratish uchun let kalit so'zi ishlatiladi. Quyidagi qatorda xabar nomli o'zgaruvchi yaratamiz:

ozgaruvchi.js
// natija shu yerda chiqadi

Bu yerda ikki bosqich bor: avval let xabar bilan o'zgaruvchini e'lon qilamiz, so'ng = belgisi orqali unga "Salom" qiymatini beramiz (o'zlashtiramiz).

Ikkala amalni bitta qatorda birlashtirish mumkin — bu eng keng tarqalgan yozuv:

ozgaruvchi-qisqa.js
// natija shu yerda chiqadi

Bir nechta o'zgaruvchi

Bir nechta o'zgaruvchini bitta qatorda, vergul bilan ajratib e'lon qilish mumkin, lekin bu o'qishni qiyinlashtiradi:

let user = "Ali", age = 25, message = "Salom";

O'qish qulayligi uchun har bir o'zgaruvchini alohida qatorga yozish tavsiya etiladi:

kop-ozgaruvchi.js
// natija shu yerda chiqadi

Qiymatni o'zgartirish

O'zgaruvchining qiymatini istalgan vaqtda o'zgartirish mumkin. Eski qiymat o'chib, o'rniga yangisi yoziladi:

qiymat-ozgartirish.js
// natija shu yerda chiqadi

Bir o'zgaruvchidan boshqasiga qiymat nusxalash ham mumkin:

nusxalash.js
// natija shu yerda chiqadi
Bir o'zgaruvchini let bilan ikki marta e'lon qilish xatolikka olib keladi. Masalan let x = 1; let x = 2; — bu "x has already been declared" degan xato beradi.

Nomlash qoidalari

O'zgaruvchi nomlariga ikkita qat'iy cheklov bor:

  1. Nomda faqat harflar, raqamlar hamda $ va _ belgilari bo'lishi mumkin;
  2. Birinchi belgi raqam bo'lishi mumkin emas.

To'g'ri nomlarga misollar:

nomlar.js
// natija shu yerda chiqadi

Noto'g'ri nomlarga misol (bularni ishlatib bo'lmaydi):

let 1a;      // raqam bilan boshlanmaydi
let my-name; // chiziqcha (-) mumkin emas
O'zgaruvchi nomi katta-kichik harflarni ajratadi (case-sensitive). Ya'ni apple va APPLE — ikki xil o'zgaruvchi.
JavaScript kirill yoki boshqa alifbolardagi harflarga ham ruxsat beradi (masalan let имя), lekin amalda faqat inglizcha nomlar ishlatiladi.

camelCase uslubi

Agar nom bir necha so'zdan iborat bo'lsa, odatda camelCase uslubi qo'llaniladi: birinchi so'z kichik harf bilan, keyingi har bir so'z esa katta harf bilan boshlanadi.

camelcase.js
// natija shu yerda chiqadi
O'zgaruvchiga mazmunli nom bering. data yoki value kabi umumiy nomlardan qoching. Nomdan uning nimani saqlayotgani ma'lum bo'lsin — masalan userName, totalPrice. Yaxshi nomlar kodni o'z-o'zini tushuntiradigan qiladi.

Rezervlangan so'zlar

Ba'zi so'zlar tilning o'zi tomonidan ishlatiladi (masalan let, class, return, function). Ularni o'zgaruvchi nomi sifatida ishlatib bo'lmaydi — bu xato beradi.

let let = 5;      // xato: "let" rezervlangan
let return = 10;  // xato: "return" rezervlangan

const — o'zgarmas o'zgaruvchi

O'zgarmaydigan (doimiy) qiymatni e'lon qilish uchun let o'rniga const ishlatiladi:

const.js
// natija shu yerda chiqadi

const bilan e'lon qilingan o'zgaruvchining qiymatini o'zgartirib bo'lmaydi. Buni qilishga urinish xato beradi:

const myBirthday = "18.04.1998";
myBirthday = "01.01.2000"; // xato — const qiymatini o'zgartirib bo'lmaydi!

Agar dasturchi biror qiymat hech qachon o'zgarmasligiga amin bo'lsa, uni const bilan e'lon qiladi. Bu qiymat tasodifan o'zgarib ketishidan himoya qiladi va boshqalarga ham "bu doimiy" ekanini bildiradi.

Katta harfli konstantalar

Kod ishga tushishidan oldin ma'lum bo'lgan, "qattiq kodlangan" qiymatlar uchun ko'pincha katta harfli va pastki chiziqli nomlar ishlatiladi:

katta-const.js
// natija shu yerda chiqadi
Barcha const larni katta harf bilan yozish shart emas. Katta harflar faqat kod yozilishidan oldin ma'lum bo'lgan, "eslab qolish qiyin" qiymatlar uchun ishlatiladi. Kod ishlash paytida hisoblab olinadigan doimiylar odatiy camelCase bilan yoziladi.

var haqida

Eski kodlarda o'zgaruvchi e'lon qilish uchun var kalit so'zini uchratishingiz mumkin. U let ga o'xshaydi, lekin muhim farqlari bor va ba'zi "g'alati" xatti-harakatlarga ega.

Zamonaviy kodda var deyarli ishlatilmaydi. Har doim let yoki const dan foydalaning. var ning o'ziga xosliklarini keyinroq alohida darsda ko'rib chiqamiz.

Xulosa

  • O'zgaruvchilar ma'lumotni saqlaydi — ularni let yoki const bilan yaratamiz;
  • let — qiymati o'zgarishi mumkin bo'lgan o'zgaruvchi;
  • const — qiymati o'zgarmaydigan o'zgaruvchi;
  • Nomda harflar, raqamlar, $ va _ bo'lishi mumkin, lekin raqam bilan boshlanmaydi;
  • Ko'p so'zli nomlar uchun camelCase ishlatiladi;
  • O'zgaruvchiga mazmunli va tushunarli nom bering.
