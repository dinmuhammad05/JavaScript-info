Ma'lumot turlari

JavaScript'da qiymatlar turli xil bo'ladi: sonlar, matnlar, mantiqiy qiymatlar va hokazo. Bu darsda asosiy ma'lumot turlari bilan tanishamiz.

Asosiy turlar

JavaScript'da eng ko'p ishlatiladigan ma'lumot turlari:

1. Son (Number)

Butun va kasr sonlar uchun ishlatiladi:

let butun = 42;
let kasr = 3.14;
let manfiy = -7;

2. Satr / Matn (String)

Matnli ma'lumotlar qo'shtirnoq yoki apostrof ichida yoziladi:

let ism = "Ali";
let shahar = 'Toshkent';
let salom = `Assalomu alaykum`;  // teskari apostrof
Teskari apostrof (`) yordamida satr ichiga o'zgaruvchini ${...} orqali qo'shish mumkin. Bu "shablon satrlari" (template literals) deyiladi.
satrlar.js
// natija shu yerda chiqadi

3. Mantiqiy qiymat (Boolean)

Faqat ikki qiymatga ega: true (rost) yoki false (yolg'on):

let faol = true;
let tugagan = false;

4. undefined va null

undefined — qiymat berilmagan o'zgaruvchi. null — ataylab "hech narsa yo'q" degani:

let x;              // undefined (qiymat berilmagan)
let y = null;       // null (bo'sh qiymat)

Qiymat turini bilish

typeof operatori yordamida istalgan qiymatning turini bilib olishimiz mumkin:

typeof.js
// natija shu yerda chiqadi

Turlarni o'zgartirish

Bir turdagi qiymatni boshqasiga aylantirish mumkin. Masalan, satrni songa:

let matn = "123";
let son = Number(matn);   // 123 (son)

let raqam = 456;
let satr = String(raqam); // "456" (satr)
Ehtiyot bo'ling! "5" + 3 natijasi "53" bo'ladi (satrlar qo'shildi), lekin "5" - 3 natijasi 2 bo'ladi (sonlarga aylantirildi). JavaScript ba'zan turlarni avtomatik o'zgartiradi.

Xulosa

  • Number — sonlar (42, 3.14);
  • String — matnlar ("Salom");
  • Boolean — true yoki false;
  • undefined va null — qiymat yo'qligini bildiradi;
  • typeof — qiymat turini aniqlaydi.
