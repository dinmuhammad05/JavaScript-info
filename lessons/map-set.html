Map va Set

Endi biz murakkabroq ma'lumot tuzilmalari bilan tanishamiz: Map (kalit-qiymat juftliklari to'plami, kalit istalgan tur bo'lishi mumkin) va Set (faqat unikal qiymatlar to'plami).

Map — nima uchun kerak?

Map — xuddi Object kabi kalit-qiymat juftliklarini saqlaydi. Ammo Object dan farqli o'laroq, Map da kalit istalgan turdagi qiymat — hatto obyekt yoki funksiya — bo'lishi mumkin.

Asosiy metodlar va xususiyatlar:

  • new Map() — yangi Map yaratadi;
  • map.set(kalit, qiymat) — qiymat qo'shadi (map ning o'zini qaytaradi, zanjir qilish mumkin);
  • map.get(kalit) — kalit bo'yicha qiymatni oladi (yo'q bo'lsa undefined);
  • map.has(kalit) — kalit mavjudligini true/false bilan qaytaradi;
  • map.delete(kalit) — kalit bo'yicha o'chiradi;
  • map.clear() — hamma narsani tozalaydi;
  • map.size — elementlar soni (bu xususiyat, funksiya emas!).

Set — unikal qiymatlar to'plami

Set — qiymatlarning maxsus turdagi to'plami bo'lib, unda har bir qiymat faqat bir marta uchraydi. Kalit yo'q — faqat qiymatlar.

  • new Set(iterable) — Set yaratadi (ixtiyoriy iterable bilan to'ldiradi);
  • set.add(qiymat) — qiymat qo'shadi (set ni qaytaradi);
  • set.delete(qiymat) — o'chiradi;
  • set.has(qiymat) — mavjudligini tekshiradi;
  • set.clear() — tozalaydi;
  • set.size — elementlar soni.

Moslik uchun Set da ham keys(), values(), entries() mavjud. Set da kalit yo'qligi sababli keys() va values() bir xil natija beradi, entries() esa [qiymat, qiymat] juftliklarini qaytaradi.

Map/Set ni Object/Array bilan qachon ishlatish kerak?

  • Kalit istalgan tur (obyekt, son) bo'lsa yoki qo'shish tartibi muhim bo'lsa — Map;
  • Tez-tez qo'shish/o'chirish va size ni bilish kerak bo'lsa — Map qulayroq;
  • Faqat unikal qiymatlar to'plami kerak bo'lsa yoki mavjudlikni tez tekshirish kerak bo'lsa — Set;
  • Oddiy, JSON ga oson aylanadigan tuzilma yetarli bo'lsa — Object/Array.

Xulosa

  • Map — istalgan turdagi kalitli kalit-qiymat to'plami; set/get/has/delete/size;
  • Map qo'shish tartibini saqlaydi va obyekt kalitlarni qo'llab-quvvatlaydi;
  • Iteratsiya: keys(), values(), entries(), forEach;
  • Object.entries obyektdan Map, Object.fromEntries Map dan obyekt yasashga yordam beradi;
  • Set — faqat unikal qiymatlar to'plami; takrorlarni olib tashlash uchun ideal;
  • Ikkalasi ham iterable — for..of bilan ishlaydi.
