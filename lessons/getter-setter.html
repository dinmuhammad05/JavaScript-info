Obyekt xossalari ikki turga bo'linadi. Birinchisi — biz odatda ishlatadigan ma'lumot xossalari (data properties). Ikkinchisi — yangi tur: aksessor xossalari (accessor properties). Ular aslida qiymatni o'qish va yozishni boshqaradigan funksiyalardir, lekin tashqaridan oddiy xossaga o'xshaydi.

Getter va setter nima?

Aksessor xossalari ikkita maxsus metod bilan ifodalanadi:

  • getter — get so'zi bilan belgilanadi; xossani o'qiganimizda ishga tushadi va qiymat qaytaradi;
  • setter — set so'zi bilan belgilanadi; xossaga qiymat yozganimizda ishga tushadi va argument sifatida yangi qiymatni oladi.

Tashqi kod uchun aksessor xossa oddiy xossaga o'xshaydi: siz obj.propName deb o'qiysiz va obj.propName = value deb yozasiz — qavslar yo'q, xuddi oddiy xossadek. Ammo ostida funksiyalar ishlaydi.

Obyekt literalida getter va setter

Obyekt literalida ular get va set kalit so'zlari orqali e'lon qilinadi:

let obj = {
  get propName() {
    // obj.propName o'qilganda ishlaydi
  },

  set propName(value) {
    // obj.propName = value bajarilganda ishlaydi
  }
};

Amaliy misol: fullName aksessori name va surnamedan to'liq ismni hisoblab beradi:

getter-fullname.js
// natija shu yerda chiqadi

E'tibor bering: user.fullName — bu funksiya chaqiruvi emas (qavslar yo'q), lekin baribir get fullName metodi ishga tushdi. Bu getterning kuchi — u xossaga o'xshab ishlaydi.

Hozircha fullNameda faqat getter bor. Agar unga qiymat yozmoqchi bo'lsak — user.fullName = "..." — xatolik yuzaga keladi (yoki sokin rejimda e'tiborsiz qoladi), chunki setter mavjud emas.

Setter qo'shish

Endi fullNamega yozishni ham qo'llab-quvvatlash uchun setter qo'shamiz. U kelgan qatorni bo'sh joy bo'yicha ajratib, name va surnameni yangilaydi:

setter-fullname.js
// natija shu yerda chiqadi

Natijada bizda fullName "virtual" xossasi bor: uni o'qish ham, yozish ham mumkin, garchi u obyektda alohida saqlanmasa ham. U har safar name va surnamedan hisoblanadi.

Getter va setter — obyektning tashqi ko'rinishi (interfeysi) bilan ichki tuzilishini ajratishga imkon beradi. Foydalanuvchi fullNameni ishlatadi, ichkarida esa ma'lumot name va surnameda saqlanadi.

Aksessor deskriptorlari

Aksessor xossalarining deskriptori ma'lumot xossalaridan farq qiladi. Unda value va writable o'rniga get va set funksiyalari bo'ladi. Deskriptor kalitlari:

  • get — argumentsiz funksiya, xossa o'qilganda ishlaydi;
  • set — bitta argumentli funksiya, xossaga yozilganda ishlaydi;
  • enumerable — ma'lumot xossalaridagi kabi;
  • configurable — ma'lumot xossalaridagi kabi.
Xossa bir vaqtning o'zida ham aksessor (get/set), ham ma'lumot (value/writable) bo'la olmaydi. Agar deskriptorda ham get, ham value ko'rsatsangiz, xatolik yuzaga keladi.

Object.defineProperty bilan getter/setter

Aksessor xossani Object.defineProperty orqali ham e'lon qilish mumkin. Bu obyekt yaratilgandan keyin xossa qo'shish kerak bo'lganda foydali:

defineproperty-accessor.js
// natija shu yerda chiqadi

Aksessorlar validatsiya uchun

Getter/setterlarning eng foydali qo'llanishlaridan biri — qiymatni tekshirish (validatsiya). Setter orqali biz noto'g'ri qiymat yozilishining oldini olamiz.

Quyidagi misolda age uchun setter salbiy qiymatni rad etadi. Haqiqiy ma'lumot esa "maxfiy" _age xossasida saqlanadi:

setter-validation.js
// natija shu yerda chiqadi
Bu yerda _age ismidagi ostki chiziq (underscore) — bu shartli kelishuv. U xossa "ichki", to'g'ridan-to'g'ri chetdan tegilmasligi kerak degan ma'noni bildiradi. Bu texnik cheklov emas, balki dasturchilar orasidagi urf-odat.

Aksessorlar — moslashuvchanlik uchun

Getter/setterlar kodni kelajakda o'zgartirishni osonlashtiradi. Aytaylik, boshida name oddiy ma'lumot xossasi edi. Keyinchalik ismning uzunligini cheklash kerak bo'lib qoldi. Butun kodni o'zgartirish o'rniga, biz shunchaki nomni _namega o'zgartirib, ustiga tekshiruvchi setter qo'yamiz:

accessor-flexibility.js
// natija shu yerda chiqadi

Muhimi: tashqi kod hali ham user.name deb yozadi va o'qiydi — interfeys o'zgarmadi. Faqat ichki mantiq kuchaydi. Bu — getter/setterlarning katta afzalligi.

Hisoblangan (computed) xossa

Getterlar obyektda saqlanmaydigan, boshqa qiymatlardan hisoblanadigan xossalar yaratish uchun ideal. Masalan, to'rtburchakning yuzasi tomonlaridan har safar hisoblab beriladi:

computed-getter.js
// natija shu yerda chiqadi
areani oddiy xossa qilib qo'ymaganimiz muhim: agar shunday qilsak, width o'zgarganda area eskirib qolardi. Getter esa har safar yangi qiymatni hisoblab beradi — u har doim dolzarb.

Xulosa

  • Xossalar ikki turga bo'linadi: ma'lumot xossalari va aksessor xossalari (getter/setter);
  • Getter — get bilan belgilanadi, xossa o'qilganda ishlaydi; setter — set bilan, xossaga yozilganda ishlaydi;
  • Tashqaridan ular oddiy xossaga o'xshaydi: obj.prop va obj.prop = value;
  • Ularni obyekt literalida (get/set so'zlari) yoki Object.defineProperty orqali e'lon qilish mumkin;
  • Asosiy foydasi: validatsiya (noto'g'ri qiymatni rad etish), hisoblangan xossalar (masalan, fullName, area) va moslashuvchanlik (interfeysni buzmasdan mantiqni o'zgartirish).
