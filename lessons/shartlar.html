Shart operatorlari

Dasturlar ko'pincha vaziyatga qarab turli xil harakat qilishi kerak. Buning uchun if, else va switch operatorlaridan foydalanamiz.

if operatori

if — "agar" degani. Qavs ichidagi shart rost (true) bo'lsa, blok ichidagi kod bajariladi:

let yosh = 20;

if (yosh >= 18) {
  console.log("Siz voyaga yetgansiz");
}

if ... else

else — "aks holda" degani. Shart yolg'on bo'lsa, else bloki bajariladi:

if-else.js
// natija shu yerda chiqadi
Yuqoridagi yosh qiymatini 20 ga o'zgartirib, natija qanday o'zgarishini ko'ring.

if ... else if ... else

Bir nechta shartni ketma-ket tekshirish uchun else if ishlatiladi:

baho.js
// natija shu yerda chiqadi

Ternar operator (qisqa shart)

Oddiy shartlarni bir qatorda yozish uchun ? operatoridan foydalanish mumkin:

let yosh = 20;
let holat = yosh >= 18 ? "kattalar" : "bolalar";
console.log(holat);  // "kattalar"

Bu shart ? rostBo'lsa : yolg'onBo'lsa shaklida ishlaydi.

switch operatori

Bir o'zgaruvchini ko'p qiymatlar bilan solishtirganda switch qulayroq:

switch.js
// natija shu yerda chiqadi
Har bir case oxirida break yozishni unutmang! Aks holda dastur keyingi case larni ham bajarib ketadi.

Xulosa

  • if — shart rost bo'lsa kodni bajaradi;
  • else — shart yolg'on bo'lganda ishlaydi;
  • else if — qo'shimcha shartlarni tekshiradi;
  • Ternar ? : — qisqa shartlar uchun;
  • switch — bir qiymatni ko'p variant bilan solishtirish uchun.
