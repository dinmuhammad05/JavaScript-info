Linux va terminal

Linux va terminal nima?

Har bir dasturchi ertami-kechmi terminal bilan yuzma-yuz keladi: server sozlash, loyihani ishga tushirish, git bilan ishlash, paket o'rnatish — bularning barchasi ko'pincha qora ekranda, matnli buyruqlar orqali bajariladi. Ushbu bobda biz Linux operatsion tizimi va uning buyruq qatorini (terminalni) noldan o'rganamiz. Bu darsda esa asosiy tushunchalarni — operatsion tizim, Linux, shell, terminal — oydinlashtiramiz.

Operatsion tizim nima?

Operatsion tizim (OT, ingliz tilida operating system, qisqacha OS) — bu kompyuter apparatlari (protsessor, xotira, disk, tarmoq kartasi) bilan dasturlar o'rtasida vositachi bo'lib turadigan asosiy dastur. U diskdagi fayllarni boshqaradi, xotirani taqsimlaydi, jarayonlarni ishga tushiradi va foydalanuvchiga kompyuter bilan muloqot qilish imkonini beradi.

Eng mashhur operatsion tizimlar:

  • Windows — Microsoft ishlab chiqaradi, uy va ofis kompyuterlarida keng tarqalgan;
  • macOS — Apple kompyuterlarida (MacBook, iMac) ishlaydi, Unix asosida qurilgan;
  • Linux — bepul va ochiq kodli tizim; serverlar, bulut, Android telefonlar va dasturchilar orasida hukmron;

Dasturchilar dunyosida Linux alohida o'rin tutadi: internetdagi serverlarning katta qismi, Docker konteynerlari, bulutli platformalar (AWS, Google Cloud) — deyarli hammasi Linuxda ishlaydi. Shu sabab terminal va Linux buyruqlarini bilish — dasturchi uchun asosiy ko'nikma.

Linux nima va u qayerdan kelib chiqqan?

Linux — 1991-yilda finlandiyalik talaba Linus Torvalds tomonidan yaratilgan operatsion tizim yadrosi (kernel). Yadro — bu OTning eng markaziy qismi bo'lib, u apparat bilan bevosita muloqot qiladi. Linux bepul va ochiq kodli (open source): uning ichki tuzilishini istalgan odam ko'rishi, o'zgartirishi va tarqatishi mumkin.

Aslida "Linux" so'zi qat'iy ma'noda faqat yadroni bildiradi. To'liq ishlaydigan tizim esa yadro ustiga qo'shilgan ko'plab dasturlar (masalan, GNU vositalar) bilan birgalikda hosil bo'ladi. Shu bois ba'zan uni to'liqroq "GNU/Linux" deb ham atashadi. Amalda esa hamma qisqacha "Linux" deb qo'ya qoladi.

Distributivlar (distros)

Linux yadrosi o'zicha to'liq operatsion tizim emas. Odatda uni dasturlar to'plami, o'rnatuvchi (installer) va grafik muhit bilan birga distributiv (qisqacha distro) shaklida tarqatishadi. Distributiv — bu "ishga tayyor to'plam": yadro + kerakli dasturlar + paket menejeri.

Eng ko'p uchraydigan distributivlar:

  • Ubuntu — yangi boshlovchilar uchun eng mashhur, do'stona; server va ish stoli versiyalari bor;
  • Debian — juda barqaror, Ubuntu ham aynan shuning asosida qurilgan;
  • Fedora — eng yangi texnologiyalarni birinchi bo'lib sinaydi, Red Hat kompaniyasi homiylik qiladi;
  • CentOS / Rocky Linux / AlmaLinux — serverlar uchun, korxonalarda keng ishlatiladi;
  • Arch Linux — tajribali foydalanuvchilar uchun, hamma narsani qo'lda sozlaydigan;
  • Linux Mint — Windowsdan o'tayotganlar uchun qulay, Ubuntu asosida.
Yangi boshlovchi uchun eng yaxshi tanlov — Ubuntu. Uning buyruqlari, paket menejeri (apt) va hujjatlari internet forumlarida keng muhokama qilingan, muammoni izlab topish oson. Shu bobdagi barcha misollar Ubuntu/Debian oilasiga mo'ljallangan.

Shell va bash

Shell (qobiq) — bu siz yozgan matnli buyruqlarni qabul qilib, operatsion tizimga yetkazadigan dastur. Siz "faylni ko'chir", "papkaga kir", "dasturni ishga tushir" deb yozasiz — shell bu buyruqni tushunib, yadroga bajarishni topshiradi. Shell — foydalanuvchi bilan tizim o'rtasidagi tarjimon.

Linuxda bir necha xil shell mavjud, eng mashhurlari:

  • bash (Bourne Again SHell) — eng keng tarqalgan, aksariyat distributivlarda standart;
  • zsh — bashning kuchaytirilgan varianti, macOSda standart bo'lib qolgan;
  • sh — eng eski, sodda shell; skriptlarda mosligini saqlash uchun ishlatiladi;
  • fish — do'stona, aqlli avto-to'ldirishli zamonaviy shell.

Biz butun bob davomida bash bilan ishlaymiz, chunki u eng keng tarqalgan. Qaysi shellda ekaningizni bilish uchun quyidagi buyruqni tering:

echo $SHELL

Bu buyruq joriy shellning yo'lini chiqaradi, masalan /bin/bash. Bu yerda echo — ekranga matn chiqaruvchi buyruq, $SHELL esa joriy shellni saqlaydigan muhit o'zgaruvchisi.

Terminal nima?

Terminal (yoki terminal-emulyator) — bu shell ishlaydigan oyna, ya'ni siz buyruqlarni yozadigan va natijalarni ko'radigan dastur. Ko'pincha "terminal", "konsol", "buyruq qatori" (command line) so'zlari bir-birining o'rnida ishlatiladi.

Munosabatni sodda qilib aytsak:

  • Terminal — oyna (ekran), unda siz yozasiz va o'qiysiz;
  • Shell (masalan, bash) — o'sha oyna ichida ishlaydigan, buyruqlaringizni tushunadigan dastur;
  • Yadro (kernel) — shell topshiriqni yetkazadigan eng past qatlam.

Terminalni ochganingizda odatda quyidagiga o'xshash yozuv (prompt) ko'rasiz:

aziz@ubuntu:~$

Buni o'qib olaylik: aziz — foydalanuvchi nomi, ubuntu — kompyuter (host) nomi, ~ — joriy papka (bu yerda uy papkasi), $ — oddiy foydalanuvchi belgisi. Agar $ o'rniga # tursa, siz root (bosh administrator) sifatida ishlayapsiz degani (bu haqda "Ruxsatlar" darsida gaplashamiz).

GUI va CLI: ikki xil muloqot usuli

Kompyuter bilan ikki xil usulda muloqot qilish mumkin:

  • GUI (Graphical User Interface) — grafik interfeys: sichqoncha, tugmalar, oynalar, ikonkalar. Windows ish stoli, brauzer — hammasi GUI;
  • CLI (Command Line Interface) — buyruq qatori: hamma narsani matnli buyruqlar bilan bajarasiz.

Boshda GUI qulayroq tuyuladi, lekin CLIning katta afzalliklari bor:

  • Tezlik — bir buyruq bilan minglab faylni bir zumda o'zgartirish mumkin;
  • Avtomatlashtirish — buyruqlarni skriptga yozib, takrorlanuvchi ishlarni avtomatlashtirasiz;
  • Masofadan boshqarish — serverlarda odatda grafik interfeys umuman bo'lmaydi, faqat terminal orqali kirasiz (ssh);
  • Aniqlik va kuch — ba'zi imkoniyatlar faqat CLIda mavjud.
Grafik interfeysda "1000 ta faylni qayta nomlash" — soatlab qo'l ishi. Terminalda esa bu bitta qatorlik buyruq. Aynan shuning uchun tajribali dasturchilar terminalni afzal ko'radi.

Nega dasturchiga terminal kerak?

Zamonaviy dasturchilikda terminalsiz yashab bo'lmaydi. Mana amaliy sabablar:

  • git bilan versiyalarni boshqarish — commit, push, pull, branch;
  • npm, node, python kabi vositalarni ishga tushirish;
  • Server sozlash: Nginx, PostgreSQL, Docker — hammasi terminaldan;
  • Loyihani ishga tushirish, log'larni kuzatish, xatolarni tekshirish;
  • Bulutli xizmatlar (AWS, DigitalOcean) bilan ishlash;
  • Katta hajmdagi fayllarni tez qidirish, filtrlash, qayta ishlash.
Terminalda ko'p buyruqlar tasdiq so'ramasdan darhol bajariladi va "Savatga" (Recycle Bin) tushmaydi. Masalan, rm bilan o'chirilgan fayl butunlay yo'qoladi. Shu bois har bir buyruqni yozishdan oldin uni yaxshilab o'qing. Keyingi darslarda bu haqda alohida ogohlantiramiz.

Windows foydalanuvchisi nima qiladi?

Linux o'rnatishingiz shart emas. Windowsda ham Linux buyruqlarini o'rganish yo'llari bor:

  • WSL (Windows Subsystem for Linux) — Windows ichida to'liq Ubuntu ishga tushiradi, eng qulay yo'l;
  • Virtual mashina — VirtualBox yoki VMware orqali Linuxni alohida oynada;
  • Git Bash — Git bilan birga o'rnatiladigan, ko'p Linux buyruqlarini qo'llab-quvvatlaydigan mini-terminal;
  • Onlayn terminallar — brauzerda Linuxni sinash uchun (masalan, o'quv maqsadida).
Agar Windows 10/11 ishlatsangiz, PowerShellda wsl --install buyrug'i bir zumda Ubuntuni o'rnatib beradi. Bu — dasturchilar uchun eng ommabop yo'l.

Xulosa

  • Operatsion tizim — apparat bilan dasturlar o'rtasidagi vositachi (Windows, macOS, Linux);
  • Linux — bepul, ochiq kodli tizim; serverlar va dasturchilar dunyosida hukmron;
  • Distributiv — ishga tayyor Linux to'plami (Ubuntu, Debian, Fedora va boshqalar);
  • Shell (bash) — buyruqlaringizni tushunib tizimga yetkazadigan tarjimon;
  • Terminal — shell ishlaydigan oyna, buyruq yozadigan joy;
  • CLI tezlik, avtomatlashtirish va masofadan boshqarish imkonini beradi;
  • Dasturchiga terminal git, npm, server va bulut bilan ishlash uchun shart.
