Funksiyalar

Funksiya — bu ma'lum bir vazifani bajaradigan, qayta ishlatish mumkin bo'lgan kod bloki. Bir marta yozib, istalgancha chaqirasiz.

Funksiya yaratish

Funksiya function kalit so'zi, nomi va qavslar bilan e'lon qilinadi:

function salomBer() {
  console.log("Assalomu alaykum!");
}

salomBer();  // funksiyani chaqiramiz
salomBer();  // yana chaqiramiz

Funksiyani chaqirmaguningizcha u ishlamaydi. Chaqirish uchun nomidan keyin qavs () qo'yiladi.

Qiymat qaytarish (return)

return yordamida funksiya natija qaytaradi. Bu natijani o'zgaruvchiga saqlash mumkin:

return.js
// natija shu yerda chiqadi
return bajarilgach, funksiya darhol to'xtaydi — undan keyingi kod ishlamaydi.

Strelka funksiyalari (arrow functions)

Zamonaviy JavaScript'da funksiyalarni qisqaroq yozish mumkin. Bu "strelka funksiyalari" deb ataladi:

// Oddiy funksiya
function kvadrat(x) {
  return x * x;
}

// Xuddi shu funksiya — strelka ko'rinishida
const kvadrat2 = (x) => x * x;

console.log(kvadrat2(4));  // 16

Nima uchun funksiyalar kerak?

  • Takrorlanmaslik — bir kodni ko'p joyda ishlatish uchun qayta yozish shart emas;
  • Tushunarlilik — kod kichik, mazmunli bo'laklarga bo'linadi;
  • Oson tuzatish — xatoni bir joyda tuzatsangiz, hamma joyda tuzaladi.

Amaliy misol

Xulosa

  • Funksiya — qayta ishlatiladigan kod bloki;
  • Parametrlar orqali funksiyaga ma'lumot beriladi;
  • return natijani qaytaradi;
  • Strelka funksiyalari (=>) — qisqa yozuv usuli;
  • Funksiyalar kodni tartibli va tushunarli qiladi.
