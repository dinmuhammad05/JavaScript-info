Operatorlar

Operatorlar — bu qiymatlar ustida amal bajaradigan belgilar. Ular yordamida hisoblash, taqqoslash va mantiqiy amallarni bajaramiz.

Arifmetik operatorlar

Matematik amallar uchun quyidagi operatorlardan foydalanamiz:

  • + — qo'shish;
  • - — ayirish;
  • * — ko'paytirish;
  • / — bo'lish;
  • % — qoldiq (bo'lishdan qolgan qoldiq);
  • ** — daraja.

% (qoldiq) operatori juda foydali! Masalan, son juftmi yoki toqmi tekshirish uchun: agar son % 2 === 0 bo'lsa, son juft.

Belgilash operatorlari

Qiymat berish va uni qisqacha o'zgartirish uchun:

let x = 5;
x += 3;   // x = x + 3  →  8
x -= 2;   // x = x - 2  →  6
x *= 2;   // x = x * 2  →  12

Taqqoslash operatorlari

Ikki qiymatni solishtiradi va natijada true yoki false qaytaradi:

  • > katta, < kichik;
  • >= katta yoki teng, <= kichik yoki teng;
  • === qat'iy teng, !== qat'iy teng emas.

Har doim === (uch teng belgi) ishlating, == emas! === ham qiymatni, ham turini tekshiradi. == esa turlarni avtomatik o'zgartiradi va kutilmagan natijalar berishi mumkin (masalan, 0 == "" → true).

Mantiqiy operatorlar

Bir nechta shartni birlashtirish uchun:

  • && — VA (ikkalasi ham rost bo'lsa);
  • || — YOKI (kamida bittasi rost bo'lsa);
  • ! — EMAS (qiymatni teskarisiga o'giradi).

Xulosa

  • Arifmetik: + - * / % **;
  • Belgilash: = += -= *=;
  • Taqqoslash: > < >= <= === !== — natija true/false;
  • Mantiqiy: && (VA), || (YOKI), ! (EMAS);
  • Har doim === ni == dan afzal ko'ring.
