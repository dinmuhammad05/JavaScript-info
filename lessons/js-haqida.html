JavaScript haqida

JavaScript — bu veb-sahifalarni "jonli" qiluvchi dasturlash tili. Ushbu darsda uning tabiati, tarixi va imkoniyatlari bilan tanishamiz.

JavaScript qanday paydo bo'lgan?

JavaScript dastlab 1995-yilda faqat brauzerlarga "jon" bag'ishlash — sahifalarni interaktiv qilish uchun yaratilgan edi. Dastur kodi to'g'ridan-to'g'ri HTML sahifasiga yozilib, sahifa yuklanganda avtomatik ishga tushardi.

Bugungi kunda JavaScript nafaqat brauzerda, balki serverda (Node.js orqali), va umuman JavaScript dvigateli (engine) o'rnatilgan istalgan qurilmada ishlay oladi.

Brauzerda o'rnatilgan JavaScript dvigatelining nomlari bor: V8 — Chrome, Opera va Edge uchun; SpiderMonkey — Firefox uchun. Node.js ham V8 dvigatelida ishlaydi.

Dvigatel kodni qanday bajaradi?

Dvigatellar murakkab, lekin asosiy g'oya sodda:

  1. Dvigatel skriptni o'qiydi ("parse" qiladi);
  2. Uni mashina kodiga o'giradi ("compile" qiladi);
  3. So'ng mashina kodi tez ishga tushadi.

Dvigatel jarayonning har bir bosqichida optimallashtirish qo'llaydi, shuning uchun zamonaviy JavaScript juda tez ishlaydi.

Brauzerda JavaScript nimalar qila oladi?

  • Sahifaga yangi HTML qo'shish, mavjud mazmun va uslublarni o'zgartirish;
  • Foydalanuvchi harakatlariga javob berish — bosish, sichqoncha, tugmalar;
  • Server bilan tarmoq orqali so'rov yuborish (AJAX, Fetch), fayl yuklash;
  • Cookie olish va o'rnatish, foydalanuvchidan savol so'rash, xabar ko'rsatish;
  • Ma'lumotni brauzer xotirasida saqlash (localStorage).

Brauzerdagi JavaScript nimalarni QILA OLMAYDI?

Xavfsizlik uchun brauzerdagi JavaScript imkoniyatlari cheklangan:

Sahifadagi JavaScript diskdagi ixtiyoriy fayllarni o'qiy olmaydi yoki dasturlarni ishga tushira olmaydi. Uning operatsion tizim funksiyalariga to'g'ridan-to'g'ri kirishi yo'q.

Turli oynalar/tablar odatda bir-birini "bilmaydi" (bu "Same Origin Policy" — bir manba siyosati deb ataladi). Bu foydalanuvchi ma'lumotlarini himoya qiladi.

JavaScript'ni nimasi maxsus?

  • HTML/CSS bilan to'liq integratsiya — uchtasi birga ishlaydi;
  • Sodda ishlarni sodda bajaradi;
  • Barcha asosiy brauzerlarda qo'llab-quvvatlanadi va standart (ECMAScript) sifatida yoqilgan.
JavaScript — brauzerda ishlaydigan yagona til bo'lgani uchun eng keng tarqalgan. Uning "ustki" tillari ham bor (TypeScript, Dart), ular kodni JavaScript'ga o'giradi.

Xulosa

  • JavaScript — brauzer uchun yaratilgan, endi ko'p muhitlarda ishlaydigan til;
  • Brauzerda u DOM, hodisalar, tarmoq va xotira bilan ishlay oladi;
  • Xavfsizlik sababli uning imkoniyatlari cheklangan;
  • U HTML va CSS bilan mukammal integratsiyalashgan.
