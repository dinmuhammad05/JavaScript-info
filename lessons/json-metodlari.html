JSON metodlari, toJSON

Obyektni tarmoq orqali yuborish yoki faylda saqlash uchun uni matnga aylantirish kerak. JSON (JavaScript Object Notation) — bu ma'lumotni almashish uchun umumiy qabul qilingan format. JavaScript'da JSON.stringify va JSON.parse metodlari mavjud.

JSON.stringify

JSON.stringify(obj) — obyektni JSON satriga aylantiradi:

stringify.js
// natija shu yerda chiqadi

Hosil bo'lgan satr JSON-kodlangan (JSON-encoded) deb ataladi. Uning JavaScript obyektidan farqlari:

  • Satrlar faqat ikki tirnoqda bo'ladi (bitta tirnoq yoki backtick yo'q);
  • Obyekt kalitlari ham har doim ikki tirnoqda bo'ladi ("ism", ism emas);
  • Ortiqcha bo'shliqlar olib tashlanadi.

Qo'llab-quvvatlanadigan turlar

JSON.stringify quyidagi turlarni qo'llab-quvvatlaydi: obyektlar, massivlar, satrlar, sonlar, mantiqiy qiymatlar (true/false) va null.

supported-types.js
// natija shu yerda chiqadi

Ammo ba'zi turlar e'tiborsiz qoldiriladi yoki tashlab ketiladi:

  • Funksiyalar (metodlar);
  • undefined qiymatlar;
  • Simvol (Symbol) kalitlari va qiymatlari.
ignored-types.js
// natija shu yerda chiqadi
JSON halqasimon (circular) havolalarni qo'llab-quvvatlamaydi. Agar obyekt o'z-o'ziga havola qilsa, JSON.stringify xatolik beradi.

JSON.stringifyning uchinchi argumenti — chiroyli, o'qish oson formatlash uchun. Odatda unga bo'shliqlar soni beriladi:

Replacer — nimalarni saqlashni tanlash

Ikkinchi argument replacer — u qaysi xossalarni JSON'ga kiritishni boshqaradi. U ikki xil bo'lishi mumkin:

Massiv — faqat sanab o'tilgan kalitlar saqlanadi:

Funksiya — har bir kalit-qiymat juftligi uchun chaqiriladi. Qaytargan qiymat saqlanadi; undefined qaytarsa, xossa tashlab ketiladi:

// natija shu yerda chiqadi

JSON.parse(str) — JSON satrini yana JavaScript obyektiga aylantiradi (bu stringifyning teskarisi):

// natija shu yerda chiqadi

Massivlarni ham xuddi shunday o'qiydi:

JSON juda qat'iy: kalitlar va satrlar ikki tirnoqda bo'lishi shart, oxirida ortiqcha vergul bo'lmasligi kerak, izohlar (comment) qo'yib bo'lmaydi. Aks holda JSON.parse xatolik beradi.

Reviver — o'qishda qiymatlarni tiklash

JSON.parse(str, reviver) — ikkinchi argument sifatida funksiya berilsa, u har bir kalit-qiymat juftligini o'qishda chaqiriladi. Bu, masalan, sana satrini yana Date obyektiga aylantirish uchun kerak:

toJSON metodi

Obyektlar toString metodiga o'xshab, toJSON metodiga ega bo'lishi mumkin. Agar u mavjud bo'lsa, JSON.stringify obyektni to'g'ridan-to'g'ri aylantirish o'rniga aynan shu metodni chaqiradi:

tojson.js
// natija shu yerda chiqadi
Aslida o'rnatilgan Date obyektida ham toJSON mavjud. Shuning uchun JSON.stringify sanalarni avtomatik ravishda standart ISO satr formatida saqlaydi.

Xulosa

  • JSON.stringify(obj) — obyektni JSON satriga aylantiradi;
  • JSON.parse(str) — JSON satrini yana obyektga o'giradi;
  • Qo'llab-quvvatlanadi: obyekt, massiv, satr, son, boolean, null;
  • Tashlab ketiladi: funksiya, undefined, simvol;
  • 3-argument (bo'shliq) — chiroyli, o'qish oson formatlash uchun;
  • Replacer (2-argument) — qaysi xossalarni saqlashni tanlaydi;
  • Reviver (parse'ning 2-argumenti) — o'qishda qiymatlarni qayta tiklaydi;
  • toJSON — obyektning maxsus JSON ko'rinishini belgilaydi.
