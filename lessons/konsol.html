Ishlab chiquvchi konsoli

Kodda xatolar bo'lishi muqarrar. Ularni ko'rish va tuzatish uchun brauzerlar ishlab chiquvchi vositalari (developer tools) bilan jihozlangan.

Developer Tools nima?

Har bir zamonaviy brauzer ichida dasturchilar uchun maxsus vositalar to'plami bor. Ular xatolarni ko'rsatadi, kodni bosqichma-bosqich bajarishga va tarmoq so'rovlarini kuzatishga imkon beradi.

Konsolni qanday ochish kerak?

  • Chrome / Edge / Firefox: F12 tugmasi;
  • Mac: Cmd + Option + J (Chrome) yoki Cmd + Option + K (Firefox);
  • Yoki sahifada o'ng tugma → "Inspect" → "Console" bo'limi.

Konsol nima uchun kerak?

Console bo'limi ikki asosiy vazifani bajaradi:

  1. Kodda yuzaga kelgan xatolarni (qizil rangda) ko'rsatadi;
  2. console.log() orqali chiqarilgan ma'lumotlarni ko'rsatadi.

Quyidagi misolni ishga tushiring — natija maydonchada, xuddi brauzer konsolidagidek, ko'rinadi:

konsol.js
// natija shu yerda chiqadi
Konsolga to'g'ridan-to'g'ri JavaScript kod yozib, Enter bosish orqali ham uni bajarish mumkin.
Debugging — dasturchining asosiy mahoratlaridan biri. Konsol bilan yaxshi tanishib oling.

Xulosa

  • Har bir brauzerda developer tools mavjud (F12);
  • Console — xatolar va console.log chiqishini ko'rsatadi;
  • Konsolda kod yozib, darhol bajarish mumkin.
